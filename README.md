Final project for BIOSTAT 707. 

# Health Data Project
By: Sydney Shimizu (sydney.shimizu@duke.edu), Tirzah Asir (tirzah.asir@duke.edu), Ahmed Hussain (ahmed.hussain1@duke.edu), and Yaoyang Li (yaoyang.li@duke.edu)

## Goals
Our goal is to test whether unsupervised clustering of METABRIC gene expression recovers the PAM50 breast cancer subtypes, whether those clusters are stable under resampling, and how well regularized and tree-based models predict the subtype from a small gene set.

## Roles
Sydney: Missingness plots and exploratory analysis, PCA, k-means clustering, lasso model + calibration, writing up sections on data + PCA + k-means + lasso

Ahmed: Negative controls and sensitivity runs; lasso model and its calibration. Write up sections on calibration, evaluation of lasso model Brier Score

Tirzah: Hierarchical clustering, comparison of clusters with PAM50, random forest model, writing up sections on hierarchical clustering, stability, the forest and the baselines

Yaoyang: Stability by resampling; random forest, baselines and discrimination. Write up on random forest, baselines and discriminations.

All: Decisions on genes, k range and label  classes; discussion and limitations; fresh-clone test with a README that gives the commands and run time; review code, final presentation
